# 🚀 Featured Projects

## 1. Employee Attrition Prediction

**Business Problem:**  
Employee turnover can create challenges for organizations, including recruitment costs, productivity loss, and workforce planning. This project explores employee-related data to predict whether an employee is likely to leave an organization.

**What I Did:**
- Analyzed employee data to understand workforce patterns and attrition trends.
- Performed Exploratory Data Analysis (EDA) using visualizations.
- Cleaned data and performed categorical encoding and feature selection.
- Applied SMOTE to address class imbalance.
- Developed classification models using Decision Tree and Random Forest.
- Performed hyperparameter tuning using GridSearchCV and RandomizedSearchCV.
- Evaluated models using Accuracy, Precision, Recall, F1-score, and Confusion Matrix.

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Imbalanced-learn.

- [View Dataset](Employee-Attrition-Prediction/HR-Employee-Attrition.csv)

## 2. Loan Approval Prediction

**Business Problem:**  
Loan approval is an important decision in the banking and financial sector. This project uses applicant information, such as income, education, credit history, and loan details, to explore and predict loan approval outcomes using Machine Learning.

**What I Did:**
- Explored applicant information and identified patterns in the dataset.
- Performed data cleaning and handled missing values.
- Conducted Exploratory Data Analysis (EDA).
- Applied categorical encoding and feature scaling.
- Used SMOTE to address class imbalance.
- Developed a classification model using Support Vector Machine (SVM).
- Applied GridSearchCV for hyperparameter tuning.
- Evaluated model performance using classification metrics and a confusion matrix.

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Imbalanced-learn.
